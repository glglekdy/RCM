## 새 기능

- **배속 플레이**: 테스트 플레이에서 곡을 0.1배~5.0배로 느리게 또는 빠르게 재생할 수 있어요.
- 테스트 플레이 중 `←` `→`로 0.1씩 바꿔요. 폰에서는 `플레이 −` `플레이 +` 버튼을 눌러요.
- 플레이 도중에 바꿔도 음악과 노트가 끊기지 않고 같이 빨라지거나 느려져요. 빠르게 하면 음이 높아지고 느리게 하면 낮아져요.
- 판정 범위와 판정 오프셋은 몇 배에서든 그대로예요.
- `F5`로 다시 시작해도 값이 유지되고, 앱을 다시 켜면 1.0배로 돌아가요. 편집 화면 재생은 항상 1.0배예요.
- 노트가 내려오는 빠르기인 `배속`(`↑` `↓`)은 그대로 따로 조절해요.
