## 새 기능

- 테스트 플레이 중 F5를 누르면 처음부터 다시 시작해요.
- 테스트 플레이 중 F4로 자동 플레이를 켜고 끌 수 있어요.
- GREAT·GOOD 판정 밑에 EARLY / LATE를 보여 줘서 일찍 쳤는지 늦게 쳤는지 알 수 있어요.
- 곡이 끝나도 테스트 플레이가 바로 닫히지 않고 결과가 남아요. Esc를 눌러야 편집 화면으로 돌아가요.

## 버그 수정

- 테스트 플레이에서 노트가 툭툭 끊기며 내려오던 현상을 고쳐 부드럽게 내려와요.
- 테스트 플레이를 마치고 편집 화면으로 돌아오면 누른 키가 제목·아티스트 칸에 입력되던 문제를 고쳤어요.
- 게임플레이 설정에서 노트 너비나 판정선 위치를 크게 하면 옆의 작은 미리보기가 넘쳐 레인이 안 보이던 문제를 고쳤어요. 이제 미리보기가 크기에 맞춰 줄어들어요.
