## 새 기능

- 트랙마다 종류(플레이 / 기믹)를 고를 수 있어요. 기믹 트랙은 뮤즈대쉬 톱니바퀴처럼 게임이 해석할 데이터용이라 키가 없고 판정하지 않아요. 편집 화면에서는 빗금 레인과 속이 빈 노트로, 테스트 플레이에서는 흐린 테두리로 보여요.
- `새 프리셋`을 누르면 템플릿 창이 열려요. 빈 프리셋, 기본 4K~8K, DJMAX RESPECT V, EZ2ON REBOOT : R, Muse Dash, osu!mania 배치를 골라 바로 만들 수 있어요.
- 음악 없이 프로젝트를 만들고, 나중에 곡 탭의 `음악`에서 고르거나 바꿀 수 있어요.
- 홈 화면이 부드럽게 움직여요. 사이드바로 페이지를 바꿀 때, 템플릿 카드가 펼쳐질 때, 창이 열릴 때 자연스럽게 나타나요.
- 앱 아이콘이 더 밝아졌어요.

## 바뀐 점

- 트랙 폭(좁게 · 보통 · 넓게) 설정이 없어졌어요. 예전 채보의 폭 값은 문제없이 열리고, 다음에 저장할 때 빠져요.
- 기본 트랙 프리셋이 4K · 5K · 6K · 8K로 간단해졌어요. 처음 설치하거나 `기본값 복원`을 누를 때 적용돼요.
- 키 이름 `'` `,` `.` `/`가 기호로 보여요.
