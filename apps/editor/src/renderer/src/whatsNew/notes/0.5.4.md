## 새 기능

- `AI 가이드` 맨 위에 **자동 문서 업데이트**가 생겼어요. 게임 프로젝트에 넣어 둔 `CHART_FORMAT_GUIDE.md` 위치를 추가해 두면, 에디터가 업데이트될 때마다 그 파일도 새 가이드로 바뀌어요.
- `위치 추가`를 눌러 폴더를 고르면 그 자리에 지금 가이드를 저장하고 목록에 넣어요. 이미 있는 가이드 파일을 고르면 새 내용으로 덮어써요.
- 같은 이름의 다른 파일을 덮어쓰지 않도록 직접 추가한 파일만 바꿔요. 옮기거나 지운 파일은 다시 만들지 않고 "파일을 찾을 수 없어요"로 알려 줘요.
- 목록에서 X를 누르면 자동 업데이트에서만 빠지고 파일은 그대로 남아요.
