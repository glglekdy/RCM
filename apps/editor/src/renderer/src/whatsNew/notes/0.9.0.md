## 새 기능
- **웹 버전 정식 공개**: 설치 없이 폰·PC 브라우저에서 채보를 만들고 편집할 수 있어요 → https://glglekdy.github.io/RCM/main/
  - 폰 세로·가로 화면 배치, 손가락으로 편집(한 손가락 편집, 두 손가락 스크롤·줌, 길게 눌러 메뉴, 이동 도구)
  - 폰에서 테스트 플레이: 레인을 손가락으로 치고, 전체 화면·화면 꺼짐 방지
  - 홈 화면에 설치하면 오프라인에서도 열리고, 새 버전이 나오면 알려 줘요
  - 화면이 가려지면 자동 저장해요(설정에서 끌 수 있어요)
  - 프로젝트는 브라우저에 저장되고, 기기를 옮길 때는 프로젝트 ZIP을 써요
- **판정 오프셋**: 설정 → 판정에서 −200~+200ms로 맞출 수 있어요. 테스트 플레이에 바로 적용돼요
- **프로젝트 ZIP 내보내기**: 파일 메뉴에서 프로젝트를 ZIP 하나로 내보내고 가져올 수 있어요
- **공지사항**에 이미지를 넣을 수 있어요

## 버그 수정

- 불러오기에 실패한 프로젝트가 닫히지 않던 문제를 고쳤어요
