# 자유 위치형(모바일) 채보 설계

- 작성일: 2026-10-19
- 범위: `core` 포맷 → 에디터 편집 → `playfield` 렌더링·테스트 플레이

## 0. 사용자가 정한 것
- 프로세카·츄니즘처럼 노트가 레인이 아닌 **가로 위치 + 폭**을 가지는 채보
- 노트 종류: 탭, **플릭**, **슬라이드(연결)**, **트레이스**
- 가로 칸 수는 **채보마다 지정** (기본 12)
- 플릭 방향 규칙도 **채보마다 지정**: 5방향(`directional`) 또는 방향 무관(`any`)

## 1. 포맷

기존 레인형 채보(`Chart`)는 바뀌지 않는다. `layout: "free"`가 있는 채보만 자유형이다.

```jsonc
{
  "formatVersion": 1,
  "layout": "free",
  "name": "MASTER",
  "level": 30,
  "columns": 12,              // 1~32 정수
  "flickMode": "directional", // "directional" | "any"
  "speeds": [],               // 레인형과 같음 (선택)
  "notes": [
    { "tick": 0, "type": "tap", "x": 0, "width": 3 },
    { "tick": 480, "type": "trace", "x": 4, "width": 2 },
    { "tick": 960, "type": "flick", "x": 6, "width": 3, "direction": "upLeft" },
    { "type": "slide", "points": [
        { "tick": 1440, "x": 0, "width": 3, "ease": "easeOut" },
        { "tick": 1920, "x": 4, "width": 3, "hidden": true },
        { "tick": 2400, "x": 9, "width": 3 }
      ], "endFlick": true, "direction": "up" }
  ]
}
```

- `x`: 왼쪽 끝 칸 위치(0 이상), `width`: 칸 수(0보다 큼). 소수 허용. `x + width ≤ columns`.
- `direction`: `up | left | right | upLeft | upRight`. `flickMode`가 `directional`이면 플릭(과 `endFlick` 슬라이드)에 필수, `any`면 쓰면 안 된다.
- 슬라이드 `points`: 2개 이상, tick은 점점 커져야 한다. `ease`(`linear` 기본 | `easeIn` | `easeOut`)는 그 지점에서 다음 지점까지의 이동 곡선. `hidden`은 중간 지점에만 쓸 수 있고, 판정 없이 경로만 꺾는다.
- 겹침 금지: 같은 tick에서 가로 구간이 겹치는 단발 노트(탭·플릭·트레이스·슬라이드 시작)끼리. 슬라이드 몸통끼리의 교차는 허용.
- 레인형의 hold는 자유형에서 "지점 2개, 위치가 같은 슬라이드"로 표현한다.

## 2. 에디터 (2~3단계)
- 타임라인 가로축 = 연속 격자. 드래그로 폭 지정, 양 끝 드래그로 폭 조절, 기본 칸 스냅.
- 방향 플릭은 누른 채 끈 방향으로 만든다 (그 방향을 다음 플릭 기본값으로 기억). 방향 무관 채보는 옆으로 끌면 폭.
- 연속 그리기(G): 끌고 지나간 스냅 tick마다 포인터 칸의 노트를 깐다 (한 기록). 슬라이드면 경로를 따라 슬라이드 하나, 꺾이는 곳은 숨은 지점.
- 슬라이드는 먼저 옆으로 끌면 시작 폭, 위로 끌면 끝 지점. 채보 탭에서 폭을 전체·지점별로 숫자로 정한다.
- 도구: 탭 / 트레이스 / 플릭(방향) / 슬라이드(지점 클릭으로 이어 붙이기, 지점 드래그 이동).
- 채보 패널: 칸 수, 플릭 방식.

## 3. playfield (4단계)
- 자유형 렌더러, 폰 세로/가로 비율 선택.
- 오토 미리보기. PC 테스트 플레이는 마우스(단일 터치)만 가능하므로 동시 터치는 판정하지 않는다.

## 4. 단계
1. core: 타입, 검증, 읽기·저장, AI 가이드 문서
2. 에디터: 자유형 채보 만들기, 탭·트레이스·플릭 편집
3. 슬라이드 편집
4. playfield 렌더링, 오토, 마우스 테스트 플레이
